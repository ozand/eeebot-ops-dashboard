Privacy policy

eeebot channel publisher · last updated 15 September 2026

Summary

This program uploads videos to a single YouTube channel owned by the same person who runs it, and reads that channel's own aggregate statistics. It has no other users, collects no data about anyone else, and shares nothing with third parties.

Who operates it

An individual, for personal and experimental use, contactable at ozand13ai1@gmail.com. There is no company and no service offered to the public.

What Google user data is accessed

Two OAuth scopes are requested, and no others:

youtube.upload          upload a video to the owner's own channel,
                        and set its title and description
yt-analytics.readonly   read that channel's own aggregate statistics

The analytics data consists of counts — views, subscribers, returning viewers. It contains no names, no messages and no information identifying any individual viewer.

Scopes covering comments, community posts, subscriptions, playlists, other channels or any other person's content are not requested. The program has no technical ability to read or write them.

What is stored, and where

  • An OAuth refresh token and client credentials, in a single file on the owner's own computer, readable only by the account that runs the program.
  • The numeric statistics described above, in local files on that same computer.
  • The videos themselves, which the owner publishes to their own channel.

Nothing is stored on any server operated by us, because there is no such server. The machine in question is a single netbook on a home network.

What is not done with it

  • Not transferred, sold, rented or disclosed to any third party.
  • Not used for advertising, profiling, or audience measurement beyond the owner's own channel.
  • Not used to develop, improve or train any generalised artificial-intelligence or machine-learning model.
  • Not used for any purpose other than publishing the owner's videos and reading the owner's own statistics.

Use of Google user data adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Retention and deletion

The stored token remains valid until it is revoked or deleted. The owner can revoke this program's access at any time at myaccount.google.com/permissions, which renders the stored token useless immediately. Deleting the local credential file removes it entirely. Requests to delete any data held by this program can be sent to the contact address above and will be actioned by deleting the relevant local files.

Children

The program is not directed at children and collects no data from them. The channel it publishes to is not designated as made for children.

Changes

If this policy changes, the revised version is published at this address with a new date. The page's history is public in the repository that serves it.
